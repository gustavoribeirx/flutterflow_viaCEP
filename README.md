# 📍 FlutterFlow ViaCEP

Este repositório contém um projeto desenvolvido em **Flutter** através da plataforma **FlutterFlow**, focado na integração com a API pública do **ViaCEP** para consulta automatizada de endereços.

## 🚀 O Projeto

O objetivo desta aplicação é demonstrar a viabilidade de integração de APIs REST dentro do ecossistema FlutterFlow, permitindo que o usuário digite um CEP e receba instantaneamente os dados de:
* Logradouro
* Bairro
* Cidade (Localidade)
* Estado (UF)

## 🛠 Tecnologias e Recursos

* **[FlutterFlow](https://flutterflow.io):** Plataforma utilizada para o design da UI e lógica de navegação.
* **[ViaCEP](https://viacep.com.br):** Webservice utilizado para o consumo dos dados de endereçamento.
* **Dart/Flutter:** Linguagem e framework base gerados pelo projeto.

## 📱 Funcionalidades

- [x] Consulta de CEP em tempo real.
- [x] Tratamento básico de erros (CEP inexistente ou inválido).
- [x] Interface limpa e responsiva.
